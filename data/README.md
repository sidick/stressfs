# data/

Empty stub through M0–M2 (docs/implementation-plan.md section 1 and milestone
M3).

This holds `stressfs.quirks`, the single-source quirks file (match
conditions, actions, confidence tiers) that `docs/quirks.md` is generated
from. It is seeded with real entries at M3, once the conform table (M1) and
report/verdict machinery (M2) it refers to actually exist — a quirks file
with nothing to apply to would be fiction.
